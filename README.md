# Python CRUD API 🐍

My first REST API built with Python, created to practice and understand the fundamentals of backend development and API design.

This project implements the core **CRUD operations**:

* **Create** — Add new data
* **Read** — Retrieve existing data
* **Update** — Modify existing data
* **Delete** — Remove data

## 🎯 What I Learned

Through building this project, I practiced:

* Designing RESTful API endpoints
* Working with HTTP methods such as `GET`, `POST`, `PUT/PATCH`, and `DELETE`
* Handling requests and responses
* Working with JSON data
* Using HTTP status codes
* Structuring a Python backend project
* Implementing CRUD logic
* Testing and debugging API endpoints

## 🚀 Purpose

This project is part of my journey into **backend development with Python**. The main goal was not just to make the endpoints work, but to understand how an API handles the flow:

**Client Request → Route → Business Logic → Data → Response**

It serves as a foundation for learning more advanced backend concepts such as databases, authentication, validation, error handling, API architecture, and eventually building production-ready APIs.
